# Construction Cost Prediction

## Project Overview
Construction Cost Prediction is a Django-based web application designed to help users estimate construction costs based on the details provided. It aims to make preliminary construction budgeting easier and more convenient.

## Features
- User registration and login
- Admin login and management
- Construction cost prediction
- User-friendly web interface
- Organized project modules

## Technologies Used
- **Frontend:** HTML, CSS, SCSS, JavaScript
- **Backend:** Python, Django
- **Database:** SQLite (if configured in the project)

## Project Structure
- `ConstructionCost/` – Main Django project configuration
- `admins/` – Admin-related application
- `users/` – User-related application
- `utility/` – Utility modules
- `assets/` – Static assets
- `media/` – Media files
- `manage.py` – Django management script

## How to Run the Project

1. Install Python and Git.
2. Clone the repository:

   ```bash
   git clone https://github.com/26a35a4415/Construction-Cost-Prediction.git
   ```

3. Open the project folder containing `manage.py`.
4. Install Django and the other dependencies required by the project.
5. Configure the environment variables and database settings.
6. Run database migrations:

   ```bash
   python manage.py migrate
   ```

7. Start the development server:

   ```bash
   python manage.py runserver
   ```

8. Open `http://127.0.0.1:8000/` in your browser.
